### `> ls /projects --sort=impact`

<details>
<summary><b>PractiCIS · CVs con IA en formato Harvard</b></summary>
<br>

Fundador y desarrollador. Plataforma web con IA generativa que analiza y estructura currículums bajo el estándar Harvard a partir de lenguaje natural.

`Stack:` FastAPI · Next.js · Supabase · LLMs
</details>

<details>
<summary><b>Qaipu · Asistente financiero por Telegram</b></summary>
<br>

Asistente conversacional para que pequeñas empresas registren ventas y gastos (incluso con notas de voz) y consulten sus ingresos y egresos. Consolida todo en Google Sheets automáticamente.

`Stack:` Next.js · TypeScript · Gemini Flash Lite · Google Cloud Run · Google Sheets
</details>

<details>
<summary><b>QaliRoad · SafetyTech para monitoreo de conductores</b></summary>
<br>

Sistema de monitoreo de conductor asistido por IA. La detección corre 100% en el navegador (somnolencia con EAR/PERCLOS, bostezos, distracción y uso de teléfono) y una arquitectura de microservicios se encarga de alertas, reportes, notificaciones por Telegram y panel de supervisión en tiempo real.

`Stack:` React 19 · Vite · TypeScript · NestJS (6 microservicios) · Docker Compose · Supabase · MediaPipe · TF.js · GitHub Actions

[🔗 Ver repositorio](https://github.com/Ismaelrojas0112/QaliRoad)
</details>

<details>
<summary><b>Qalifood · Dietas personalizadas con IA 🏆</b></summary>
<br>

App móvil que genera dietas accesibles según presupuesto, región y estacionalidad mediante agentes de IA, pensada para combatir la anemia y la desnutrición. **1er puesto** en la Hackathon de IA (Soluciones Sostenibles) de la Embajada de EE. UU. en Perú, entre más de 100 equipos. Desarrollé el frontend.

`Stack:` Flutter · Agentes de IA
</details>

<details>
<summary><b>FacturAI · Agente de facturación electrónica</b></summary>
<br>

MVP para el reto de NTT DATA. Un agente interpreta lenguaje natural y genera comprobantes electrónicos, automatizando el cálculo de impuestos y la estructura en JSON/PDF. Seleccionado entre las soluciones destacadas del reto.

`Stack:` Gemini API · JavaScript

[🔗 Ver repositorio](https://github.com/Ismaelrojas0112/AgenteDeFacturacionAI_ConcursoNTTData)
</details>

<details>
<summary><b>Detector de incendios · Visión por computadora + IoT</b></summary>
<br>

Sistema automatizado de seguridad que combina visión por computadora con IA e IoT para la detección temprana de incendios y la respuesta inmediata.

[🔗 Ver repositorio](https://github.com/Ismaelrojas0112/detector-de-incendios)
</details>

<details>
<summary><b>IEEE CIS UNI · Sitio web de la sociedad</b></summary>
<br>

Proyecto colaborativo del sitio web de IEEE Computational Intelligence Society en la UNI.

`Stack:` TypeScript

[🔗 Ver repositorio](https://github.com/IEEE-CIS-UNI/ieee-cis-uni-website)
</details>
